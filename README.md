# tree-sitter-gitignore

[![CI](https://github.com/konomanoasa/tree-sitter-gitignore/actions/workflows/ci.yaml/badge.svg)](https://github.com/konomanoasa/tree-sitter-gitignore/actions/workflows/ci.yaml)
[![crates.io](https://img.shields.io/crates/v/konomanoasa-tree-sitter-gitignore)](https://crates.io/crates/konomanoasa-tree-sitter-gitignore)
[![npm](https://img.shields.io/npm/v/@konomanoasa/tree-sitter-gitignore)](https://www.npmjs.com/package/@konomanoasa/tree-sitter-gitignore)

[Tree-sitter](https://tree-sitter.github.io/tree-sitter/) grammar for
Git ignore files 2.55.0.

## Installation

```sh
npm install @konomanoasa/tree-sitter-gitignore
```

## Development

Development uses Node.js 24.21.0 or later.

```sh
npm install
npm run build
npm test
```

## Specification

[Git 2.55.0 gitignore manual](https://git-scm.com/docs/gitignore/2.55.0)
