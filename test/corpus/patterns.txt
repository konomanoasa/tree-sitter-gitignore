==================
Leading spaces preserve literal comment and negation markers
:cst
==================
 #a !b
---

0:0 - 0:6   document
0:0 - 0:6     pattern
0:0 - 0:6       glob_literal ` #a !b`

==================
Inline hash is literal
:cst
==================
a#b
---

0:0 - 0:3   document
0:0 - 0:3     pattern
0:0 - 0:3       glob_literal `a#b`

==================
Negation without a pattern is preserved
:cst
==================
!
---

0:0 - 0:1   document
0:0 - 0:1     pattern
0:0 - 0:1       negation: negation `!`

==================
Slash-only pattern is preserved
:cst
==================
/
---

0:0 - 0:1   document
0:0 - 0:1     pattern
0:0 - 0:1       path_separator `/`

==================
Negation applies only once
:cst
==================
!!a
---

0:0 - 0:3   document
0:0 - 0:3     pattern
0:0 - 0:1       negation: negation `!`
0:1 - 0:3       glob_literal `!a`

==================
Escaped special markers
:cst
==================
\#\!\*\?\[
---

0:0  - 0:10   document
0:0  - 0:10     pattern
0:0  - 0:2        escape `\\#`
0:2  - 0:4        escape `\\!`
0:4  - 0:6        escape `\\*`
0:6  - 0:8        escape `\\?`
0:8  - 0:10       escape `\\[`

==================
Tabs are not trimmed
:cst
==================
a	
---

0:0 - 0:2   document
0:0 - 0:2     pattern
0:0 - 0:2       glob_literal `a\t`

==================
Escape before LF is rejected
:error
==================
foo\
next

==================
\

a\
